# NTE AI Character Tracker

A personal Neverness to Everness companion for Bond progression, Fons planning, character builds, team optimization, and future machine-learning experiments.

## Roadmap

- [x] Project foundation
- [x] Bond Lv.10 calculator
- [x] Gift/Fons/time calculations
- [ ] Character database
- [ ] Account dashboard
- [ ] Build and team planner
- [ ] Resource optimizer
- [ ] AI upgrade advisor
- [ ] Damage prediction model
- [ ] ML training/evaluation notebooks

## Project structure

```text
app/        Web application
ml/         Machine-learning experiments and models
data/       Game/build datasets
notebooks/  Exploratory analysis
```

## Goal

The long-term goal is to build a transparent AI/ML-powered NTE optimizer. Recommendations should show the reasoning behind an upgrade instead of simply returning a score.

> Game values are community-maintained and should be verified when patches change them.
