# Machine Learning Roadmap

This folder is reserved for the project's data and ML pipeline.

## Planned stages

1. Collect character/build/weapon/module/damage observations.
2. Clean and validate data.
3. Engineer features such as crit rate, crit damage, ATK, character level, skill levels and team composition.
4. Establish a simple baseline (linear regression / tree model).
5. Evaluate prediction error with a held-out test set.
6. Build an upgrade-ranking model that predicts expected value from an available resource budget.
7. Compare ML recommendations against transparent rule-based recommendations.

The goal is an explainable model, not an arbitrary black-box score.
